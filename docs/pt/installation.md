# 🛠️ Instalação

1. Baixe o arquivo `.zip` ou clone o repositório.
2. Extraia a pasta no diretório `filter/` do seu Moodle e dê a ela o nome `studiolms`.
   Caminho final: `seu-moodle/filter/studiolms/`
3. Acesse **Administração do site > Notificações** para concluir a instalação. O filtro é ligado na primeira instalação (um site que já o tem mantém a configuração dele).
4. Opcional: em **Administração do site > Plugins > Filtros > StudioLMS widgets**, desligue os widgets que não quiser e defina o tamanho mínimo da turma da barra do fórum.

O filtro não guarda nada próprio (nenhuma tabela), só um cache das contagens de participação.
