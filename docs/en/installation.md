# 🛠️ Installation

1. Download the `.zip` file or clone the repository.
2. Extract the folder into your Moodle `filter/` directory and name it `studiolms`.
   Final path: `your-moodle/filter/studiolms/`
3. Visit **Site administration > Notifications** to finish the installation. The filter is turned on at the first installation (a site that already has it keeps its own setting).
4. Optional: under **Site administration > Plugins > Filters > StudioLMS widgets**, turn off the widgets you do not want and set the minimum class size of the forum bar.

The filter stores nothing of its own (no table), only a cache of the participation counts.
