# StudioLMS widgets (`filter_studiolms`)

Moodle plugin of type `filter`. Requires Moodle 4.5 or later.

## Installation

Copy the plugin folder to `filter/studiolms` inside your Moodle directory, then visit
*Site administration > Notifications* (or run `php admin/cli/upgrade.php`).
